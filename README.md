# AI File Organizer Pro

AI File Organizer Pro is a Python desktop application that automatically organizes messy folders into categories like Images, Videos, Documents, Music, and more.

## 🚀 Features
- One-click file organization
- Clean GUI interface
- Automatic folder creation
- Organizes files by extensions
- Fast and lightweight
- Installable desktop application

## 🛠 Built With
- Python
- Tkinter
- File Handling
- OS Module
- PyInstaller
- Inno Setup

## 💻 How to Run
1. Download the project
2. Run the `.exe` setup file
3. Select a folder
4. Click "Organize Files"
